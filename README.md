# TAG IT Network organization profile

This special repository manages the public presence and shared community standards for the [`TAG-IT-NETWORK`](https://github.com/TAG-IT-NETWORK) GitHub organization.

## What lives here

| Path | Purpose |
|:--|:--|
| [`profile/README.md`](profile/README.md) | Public organization profile displayed on the TAG IT Network GitHub homepage |
| [`assets/`](assets) | Approved visual assets used by the organization profile |
| [`SECURITY.md`](SECURITY.md) | Default vulnerability disclosure policy for repositories without their own policy |

Repository-specific community health files take precedence when they exist.

## TAG IT Network

TAG IT Network creates verifiable identity infrastructure for physical assets by connecting NFC-enabled products to cryptographic digital twins and trusted on-chain lifecycle records.

- [Website](https://www.tagit.network)
- [Documentation](https://github.com/TAG-IT-NETWORK/tagit-docs)
- [Protocol contracts](https://github.com/TAG-IT-NETWORK/tagit-contracts)
- [Security policy](SECURITY.md)

For general enquiries, contact **info@tagit.network**. To report a vulnerability, contact **security@tagit.network**.
